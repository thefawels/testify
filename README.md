# Testify

Минималистичное PWA для тестов из CSV.



## Что умеет

- Импорт CSV.
- Случайный порядок вопросов и ответов при каждом прохождении.
- Пояснение к выбранному ответу, таймер и повторение ошибок.
- Общая статистика, календарь активности, динамика и история по тестам.
- Удаление тестов и отдельный сброс статистики.
- Установка на главный экран и офлайн-работа после первого успешного открытия.

## Файлы

- `docs/` — готовое приложение.
- `docs/app.js` — интерфейс и логика тестов.
- `docs/csv.js` — чтение и проверка CSV.
- `docs/test-data.js` — работа со статистикой и перемешивание.
- `docs/analytics.js` — расчёт метрик.
- `docs/tap-guard.js` — защита от случайного выбора при прокрутке.
- `docs/style.css` — оформление.
- `docs/manifest.webmanifest` — название, запуск и иконки PWA.
- `docs/sw.js` — офлайн-кеш.
- `assets/icon-source.png` — исходник временной иконки.
- `scripts/generate-icons.py` — создание PNG нужных размеров.


## Формат CSV

```csv
question_id,question,answer,is_correct,comment
1,Сколько будет 2 + 2?,4,1,Два плюс два равно четырём.
1,Сколько будет 2 + 2?,5,0,Пять получится если к двум прибавить три.
```

Каждая строка — один вариант ответа. Для одного вопроса одинаковые `question_id` и `question`; от 2 до 8 вариантов; ровно один `is_correct=1`. Остальные — `0`. Кодировка UTF-8, разделитель — запятая или точка с запятой. Пример можно скачать в самом приложении. Если текст содержит разделитель, заключай поле в двойные кавычки.
